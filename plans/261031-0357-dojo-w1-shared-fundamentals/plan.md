# Dojo W1: Shared Fundamentals (Days 1-3)

## Overview

Week 1 of the Dojo 15-day Claude Code training ([master plan](https://dojo.agilityio.dev/index.html), [fundamentals](https://dojo.agilityio.dev/fundamentals.html)). Everyone takes a ticket from read, reproduce, fix, PR, review, to merge, using git properly and Claude as a daily tool. Phase 1 (Day 0) builds the Android training app this repo uses for every exercise.

Track: Developer (mobile, Android). Solo run: you play every role (lead/client, BA, QA, dev); separate Claude sessions stand in for client, partner and peer reviewer. Feature names verified by Dojo on 2026-10-07; re-check linked docs before each week.
