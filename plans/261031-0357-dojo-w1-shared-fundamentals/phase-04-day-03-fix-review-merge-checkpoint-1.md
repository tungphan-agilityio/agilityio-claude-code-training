# Phase 4: Day 3: Fix, Review, Merge (Checkpoint 1)

## Overview

Fix the Day-2 bug on a branch with a test, ship a self-contained PR, cold-review a second PR, merge with a conflict resolved.

Source: [day-03.html](https://dojo.agilityio.dev/schedule/day-03.html)

## Todo

- [ ] Fix the Day-2 bug on a branch with small commits and the test passing
- [ ] Draft PR description with Claude (what, why, how tested, screenshots), then hand-edit
- [ ] Open PR against the training repo; keep CI green
- [ ] Solo peer swap: open a second small PR (another seeded ticket); next day or in a fresh session, judge if it can be reviewed from the description alone
- [ ] Review the second PR cold with checklist order: correctness, tests, readability, security basics, scope (3+ actionable comments posted on GitHub); optionally compare with a Claude reviewer subagent
- [ ] Resolve seeded conflict on your PR, merge, delete branch

## Exercise

Draft-then-own PR description; review with the checklist.

## Deliverables

- [ ] Branch with fix + test
- [ ] PR with self-contained description
- [ ] Cold review of second PR with 3 actionable comments
- [ ] Merged PR, conflict resolved, branch deleted

## Checkpoint (pass criteria)

- [ ] Reproduce the assigned bug and write the repro in the ticket
- [ ] Fix on a branch with a test
- [ ] Open a PR with a self-contained description
- [ ] One cold review (solo stand-in for peer review) with 3 actionable comments and one merge with conflict resolved

## Notes / Skills

Review checklist followed by hand today; becomes a `review-checklist` skill on Day 7. If failed: repeat the exercise as paired homework on Days 4-5.

## Success Criteria

All checkpoint items checked.
